# nexusUI Design Tokens

These are the global design tokens established at the organization level. They are configured via custom properties in the main `tailwind.css` theme configuration and are globally accessible as Tailwind CSS utility classes.

## Typography

We use **Inter** for body text and interface elements, and **Outfit** for headings.

### Font Families
- **Sans (Body)**: `'Inter', sans-serif` (Default body text)
- **Heading**: `'Outfit', sans-serif` (Section headers and emphasis)
